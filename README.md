# SmartCompany

**شركة محمد مصطفى الذكية** — نظام محاسبة وإدارة شركات.

## المنصات
- Android: Java + SQLite.
- Windows: المرحلة التالية مع الحفاظ على نفس منطق الحسابات والبيانات.

## النسخة
1.0.1 — بناء Android تجريبي عبر GitHub Actions.

## المكونات الحالية
- قفل التطبيق بكلمة مرور.
- الأصناف والمخزون.
- العملاء والموردون.
- المبيعات والمشتريات.
- الصندوق.
- الموظفون والرواتب والسلف.
- القيود اليومية ودليل الحسابات.
- التقارير والطباعة.
- اسم المحاسب في المطبوعات.
- مراسلة البريد الإلكتروني.

> هذه النسخة مرحلة بناء واختبار، وليست بعدُ الإصدار التجاري النهائي الموقّع.
